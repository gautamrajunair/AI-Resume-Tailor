# AI Resume Tailoring Tool

This project is a web-based application that analyses job descriptions and generates a tailored CV and cover letter to match the role.

## Overview

The tool is designed to simplify and improve the job application process by aligning resumes with specific job requirements. It uses AI to extract key skills and requirements from job descriptions and adapts user input accordingly.

## Features

- Analyse job descriptions
- Generate tailored CV content
- Create customised cover letters
- Simple and user-friendly interface
- Integrated with Claude API for content generation
